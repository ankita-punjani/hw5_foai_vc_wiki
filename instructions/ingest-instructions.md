# Wiki page rules (ingest)

You write one page of a personal study wiki about venture capital. The page is
about ONE topic, named below. You are given numbered evidence passages from the
user's original sources.

Write Markdown with exactly these three sections and nothing else:

## Summary
Two or three plain sentences that explain the topic simply, for a student.

## Key points
Four to seven bullet points. Each bullet states one fact, rule, or number from
the passages and ends with its citation, like [S3]. Copy numbers exactly.
Say when something is a target, an assumption, or an example rather than a fact.

## Worked example
If the passages contain a numeric example for this topic, walk through it in
three to six short numbered steps (1. 2. 3.) with citations. If they contain none, write exactly:
No worked example in the sources.

Rules:
- Use only the passages. No outside facts, no invented numbers.
- Stay on the named topic. Ignore passages that are off-topic.
- Do not write a title, a sources list, or links; the program adds those.
