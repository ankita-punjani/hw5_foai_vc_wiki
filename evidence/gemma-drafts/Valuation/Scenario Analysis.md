# Scenario Analysis

> Probability-weighted exit scenarios with dilution and time.
> Topic: [[index#Valuation|Valuation]] · From: [[Haas Venture Valuation Slides]]

## Summary
Scenario analysis is a method used to estimate venture capital valuations by considering different potential outcomes, including probabilities, dilution from future funding rounds, and the passage of time. This technique helps in understanding the shape of the risk and provides a language for discussions within a partnership.

## Key points
* Scenario analysis involves picking end-state scenarios [^1].
* Key variables to estimate include premoney and money, exit scenarios, potential outcomes and growth, dilution from future financings, and time [^1].
* Scenario analysis steps include picking end state scenarios, considering dilution of later rounds, determining probabilities and time, and analyzing the valuation and risk profile [^1].
* Assumptions are key in scenario analysis and can sometimes overwhelm the mathematical calculations [^2].
* The analysis uses comparables to support scenarios of four exit values and probabilities: IPO, high sale, low sale, and $0 [^3].
* Dilution from future financings is a factor considered in the analysis [^1].
* The analysis provides a language for risk, which can be used inside or outside of a partnership [^4].

## Worked example
The analysis involves comparing different scenarios based on different funding amounts. For example, if premoney is $4.5m and a raise is $500k, the resulting post-money values are calculated. This leads to different ownership percentages, such as 21%, 26%, and 34% [^5].
