# Return the Fund

> The fund-returner test and why fund size changes the exit a VC needs.
> Topic: [[index#Returns Math|Returns Math]] · From: [[Haas Venture Valuation Slides]], [[Harlem Capital Return the Fund Post]]

## Summary
The "Fund Returner" concept determines if an investment will successfully return the total capital invested by the fund. This calculation involves comparing the required exit value against the initial fund size and the expected ownership at the exit. Fund size significantly impacts the required exit value needed to achieve target returns.

## Key points
*   A $700mm exit was needed to return a $40mm fund, whereas a $350mm exit would be needed for a $20mm fund, resulting in a 50% haircut [^1].
*   Most Seed funds target a 3x – 5x gross return, which implies a return range of $120mm-$200mm for a $40mm fund [^1].
*   If Harlem Capital assumes 5% ownership at exit, it implies a total exit value of $2.4bn-$4.0bn [^1].
*   A fund may need billions in value creation to meet 3x-5x return goals, even if unicorns are not required [^1].
*   The required multiple for an early-stage fund return is 34x [^2].
*   Assuming a 25% dilution in the Seed round, the total dilution by exit is 23.5%, leading to 5.7% ownership at exit [^3].
*   Assuming a 25% to 30% dilution by exit, funds that do not have follow-on reserves may require larger exits from founders [^3].

## Worked example
The example shows that a $700mm exit is needed to return a $40mm fund [^1].
This implies that a $350mm exit would be required to return a $20mm fund, which represents a 50% haircut [^1].
If an investment of $750k were made, it would require a $4.3bn exit for a $250mm fund, which is considered VERY UNLIKELY [^1].
